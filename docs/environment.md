## Installation

Our code is mainly based on [verl](https://github.com/volcengine/verl) (v0.6.1). To prepare the environment:

```bash
conda create -n verl python==3.10
conda activate verl

# Install verl with vLLM + sglang + megatron
cd verl/
USE_MEGATRON=0 bash scripts/install_vllm_sglang_mcore.sh

# Additional dependencies
pip install math-verify tree-sitter-python evalplus
```

### Code Evaluation Dependencies

The `code_eval/coding/` directory contains the EvalPlus and LiveCodeBench tools. If missing, clone them:

```bash
# EvalPlus
cd code_eval/coding && git clone https://github.com/evalplus/evalplus && cd ../..

# LiveCodeBench
cd code_eval/coding && git clone https://github.com/LiveCodeBench/LiveCodeBench && cd ../..

# LCB benchmark data (code_generation_lite)
git clone https://hf-mirror.com/datasets/livecodebench/code_generation_lite code_eval/data/code_generation_lite
```

## Environment Variables

The scripts use the following environment variables for path configuration:

```bash
# Set ROOT to the OPSFT directory (auto-detected if not set).
export ROOT=/path/to/OPSFT

# Set PYTHON to your Python interpreter (default: python3).
export PYTHON=python3

# GPU visibility (default: all 8 GPUs).
export CUDA_VISIBLE_DEVICES=0,1,2,3,4,5,6,7

# Keep Hugging Face offline to avoid silent fallbacks to hub models.
export HF_HUB_OFFLINE=1
export TRANSFORMERS_OFFLINE=1
```

### Downloading Models

Download model checkpoints to a local directory (e.g., `huggingface.co/Qwen/`):

```bash
# Example: download Qwen3-4B
huggingface-cli download Qwen/Qwen3-4B --local-dir ./huggingface.co/Qwen/Qwen3-4B

# Teacher model for trajectory generation
huggingface-cli download Qwen/Qwen3-30B-A3B-Instruct-2507 --local-dir ./huggingface.co/Qwen/Qwen3-30B-A3B-Instruct-2507
```

All scripts accept the model path via environment variables (e.g., `BASE_MODEL`, `TEACHER_MODEL`, `MODEL_PATH`), so no code changes are needed when switching models.

## Dataset Configuration

### RL Prompt Datasets (for GRPO training)

| Dataset | Domain | Format | Description |
|---------|--------|--------|-------------|
| Eurus-2 | Code | Parquet | `prompt`, `reward_model`, `data_source` columns; code execution reward |
| DeepMath-103K | Math | Parquet | `prompt`, `reward_model` columns; math verification reward |
| DAPO-math-17k | Math | Parquet | `prompt`, `reward_model` columns; DAPO math reward |

### SFT Trajectory Datasets (teacher-generated)

Trajectory datasets are generated by `run_generate_trajectories.sh` using a strong teacher model. Each dataset contains:

| Column | Description |
|--------|-------------|
| `prompt` | Original RL prompt |
| `response` | Teacher-generated verified response |
| `ground_truth` | Ground-truth answer (code or math) |
| `teacher_verified` | Boolean: whether the response passed execution/verification |
| `source_index` | Unique prompt index (for deduplication) |
| `verification_metadata` | (optional) Verification details |

### Preparing Datasets

#### 1. RL Prompt Data

Place RL prompt parquets under `data/` or any accessible path. The parquet must contain `prompt` and `reward_model` columns.

```bash
# Example: Eurus code prompts
data/Eurus/code_train.parquet
data/Eurus/code_validation.parquet

# Example: DeepMath math prompts
data/DeepMath-103K/train_filtered_level6.parquet
```

#### 2. SFT Trajectory Data

Generate verified SFT trajectories from RL prompts using a teacher model:

```bash
# Code trajectories (execution-verified)
INPUT=data/Eurus/code_train.parquet \
OUTPUT_DIR=data/eurus_qwen3_30b_trajectories \
TEACHER_MODEL=/path/to/Qwen3-30B-A3B-Instruct-2507 \
VERIFIER=code \
    bash run_generate_trajectories.sh

# Math trajectories (math_verify or math_dapo verifier)
INPUT=data/DeepMath-103K/train_filtered_level6.parquet \
OUTPUT_DIR=data/deepmath_qwen3_30b_trajectories \
TEACHER_MODEL=/path/to/Qwen3-30B-A3B-Instruct-2507 \
VERIFIER=math_verify \
    bash run_generate_trajectories.sh
```

**Output**: `data/{output_dir}/train.parquet` and `data/{output_dir}/validation.parquet`

For large datasets, use sharding:

```bash
# Run 4 shards in parallel (one per terminal or job)
SHARD_COUNT=4 SHARD_INDEX=0 bash run_generate_trajectories.sh
SHARD_COUNT=4 SHARD_INDEX=1 bash run_generate_trajectories.sh
# ...then merge:
TRAJECTORY_DIR=data/eurus_qwen3_30b_trajectories bash run_merge_trajectory_shards.sh
```
